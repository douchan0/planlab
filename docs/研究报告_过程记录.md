## 任务来源与目标

用户提供的是一份中文行动方案（`deep-research-report.md`），内容涵盖理论依据（马克思两部类再生产、Leontief 投入产出、Kantorovich 最优规划、Lange 市场社会主义、Hayek 分散知识、Kornai 短缺经济）、建模层级、技术选型、实施路线与风险控制。

方案本身是一条"应该怎么做"的路线图，而不是一条"已经发现什么"的结论。它明确指出，如果以论文或开源为目标，合理的产物组合是：

1. 一个 MIT/BSD 许可的仿真核心；
2. 一个可复现的数据处理仓库；
3. 一组 10–20 个标准情景；
4. 一篇方法论文；
5. 一套教学 notebook。

并且给出了一个关键判断，本项目的全部设计都建立在这一判断之上：

> 最具发表潜力的主题通常不是"我写了一个计划经济模拟器"，而是更明确的问题。

方案列出四个候选方向：信息延迟对物资平衡计划稳定性的影响；配给与影子价格机制在供应冲击下的比较；投入产出网络中的计划优先级与短缺传播；计划—市场混合协调机制的计算实验。

**决定：不选其中任何一个，而是选一个能覆盖全部四个的问题。**

这是一次有意的设计取舍。四个候选若各自成篇，会产出四篇都很薄的论文；而把它们组织成一个二阶设计——**同一技术底座、同一冲击、同一信息条件，只更换协调制度**——则每个候选都成为同一篇论文的一个结果块。最终确定的主问题：

> **协调者所获信息的时间滞后与噪声，如何影响不同协调机制在投入产出经济中的稳定性与福利表现？哪种机制抑制、哪种放大随之而来的短缺动态？**

这个提问方式带来三个直接后果，事后看全部正确：

其一，它把"制度"变成了可替换模块，因此"制度比较"具有可识别性；
其二，它把"信息延迟"变成了实验处理而不是需要假设掉的噪声，因此可测；
其三，它要求一个**理论预言**——否则只是四种机制的描述性对比。这个要求最终产出了论文的解析核心。

## 研究问题的确定与理论骨架

### 为什么必须有定理

一个纯仿真对比在审稿中很难成立，因为读者会问："你的结果依赖参数吗？"若答案是"是"，则工作退化为演示。

因此在写第一行代码之前，先确立了必须由理论回答的问题：**延迟在什么条件下破坏稳定性，临界点在哪里？** 这个问题有闭式答案，而答案本身可以反过来预测仿真的稳定性边界——这就把"演示"变成了"检验"。

### 核心方程的来源

设某个信号按观察到的缺口比例调整，且观察值滞后 $k$ 期：

$$u_{t+1} = u_t - g\,u_{t-k}, \qquad u_t = \log p_t - \log p^\star$$

其特征多项式为 $z^{k+1} - z^k + g = 0$。在单位圆上代入 $z=e^{i\theta}$ 得 $|e^{i\theta}-1|=g$ 与相位条件 $(k+\tfrac12)\theta \equiv \tfrac{\pi}{2}$，解得

$$g^\star(m) = 2\sin\left[\frac{\pi}{2(2m+1)}\right] \approx \frac{\pi}{2m+1}$$

其中 $m$ 为有效时滞。边界处振荡周期恰为 $2(2m+1)$ 个季度。

这个结果有三处值得强调，且都是事后才充分理解的：

**第一，被约束的不是增益，而是增益与时滞的乘积。** 初稿写的是"每增加一期延迟，可容许增益大约减半"，这是错的：$g^\star$ 序列为 2, 1, 0.618, 0.445, 0.347…，比值趋于 1。正确的陈述是 $g^\star(m)\sim \pi/(2m+1)$，即**延迟翻倍才使增益减半**，而 $m\cdot g^\star(m)$ 单调升向 $\pi/2$。这个错误由独立验证者在第十一节记录的 F2 中发现。

**第二，$m$ 与仿真参数 $\ell$ 差一。** 引擎的时序约定是：在第 $t$ 期做计划时，协调者能看到的是第 $t-1-\ell$ 期的实现值。因此即使 $\ell=0$，也必然滞后一期。**有效时滞 $m=\ell+1$。** 若不做这个换算，理论与仿真的对比会整体错位一期——这是最可能让论文失效的单点错误，因此在架构文档、论文第 3.3 节与第 5.2 节、以及每一张表的表头都写明了。

**第三，它只对负反馈成立。** 若缺口随工具上升而增大（$b<0$），则特征多项式在 $z=1$ 处取值 $-G<0$，而 $z\to\infty$ 时趋于 $+\infty$，故对任意 $G>0$ 必存在一个大于 1 的实根——**正反馈环路没有任何可容许增益**。这条推论（论文 Corollary 4）是全部结果中最强的一条，而它是写作 agent 在整理第四节时独立导出的。

## 总体架构与分工

### 分层

架构被固定为六层，任何一层不得越界：

```
数据层 → 技术层 → 制度层 → 引擎层 → 指标层 → 实验层
```

关键设计是**引擎拥有全部会计，制度只做三个决策**：定什么目标、谁有什么优先权、价格怎么变。这样机制之间差异只来自制度，不来自代数实现。这条规则后来救了整个比较设计的可识别性。

### 冻结接口

在写任何实现前，先写下三份契约文档：

- `docs/ARCHITECTURE.md`：数据结构、机制接口、引擎时序、指标定义；
- `docs/PROTOCOL.md`：预注册，含 5 个假设及各自的证伪条件、6 个实验块、5 项统计程序、8 项效度威胁及缓解；
- `docs/DATA_SCHEMA.md`：数据层的输入输出规范。

这些文档在开工后被反复修订（见第五节），但**修订必须留下记录**——`docs/AMENDMENTS.md` 记录主实验开始前的 4 次修订，`docs/DEVIATIONS.md` 记录实验过程中的 8 项偏离。规则是：允许修订，禁止静默修订。

## 建模过程中的关键决策与返工

**这是本报告的核心章节。** 下列六次返工中，五次是我自己的实现错误，一次是方法论错误。

### 会计恒等式必须成为硬约束

第一版引擎允许每个季度的收支有微小残差。测试显示残差约 $10^{-16}$，看起来无害。

但一个仿真平台最危险的错误类别正是**小到像舍入的会计泄漏**：它不会让程序崩溃，只会让福利与短缺的排序慢慢偏掉，而所有下游结论都建立在这个排序上。

因此改为：每期强制审计

$$S_{0,i} + x_i = \sum_j Z_{ij} + C_i + G_i + I_i + S_{\text{end},i} + S^{\text{spoil}}_i$$

相对误差超过 $10^{-8}$ 即抛出 `AccountingError`。这个决定后来两次救了项目：一次抓出了机制过度申报的 bug，一次抓出了存货无界累积的问题（4.4 节）。

审计函数最终收敛为**唯一一处实现** `planlab.core.engine.balance_residual`，并要求所有测试导入它而不是各自重写。原因是 4.4 节引入溢损项后，若测试各自重写恒等式，就会有一部分测试仍在检查旧规则而显示通过。

### 从比例级联到线性规划：短边配置怎么算

**问题**：给定目标、产能、存货，实际产量是多少？

第一版采用"比例级联"：对每个商品求供给/需求的填充比，取最小者作为各部门的收缩因子，反复迭代至收敛。这在教科书式的 Leontief 模型里是标准做法。

**它彻底失败。** 冲击一个部门后，全体部门的产量迭代收敛到**零**。原因是数学性的：级联每轮把 $x$ 乘以一个小于 1 的比例 $\rho$，而 $\rho$ 本身依赖于 $x$——供给含自身产量，产量下降则供给下降，$\rho$ 不随之回升。映射的不动点只有原点。

**诊断**：在产能受限的投入产出经济中，按比例收缩**无法重新配置产出结构**。一个部门产能被砍 40%，正确的反应不是所有部门统一减产 40%，而是使用者按各自对该部门的依赖程度不同程度减产。

**修正**：把短边配置改写为一个小型线性规划

$$\max_x \sum_j x_j \quad \text{s.t.}\quad Ax - x \le r - \text{reserve},\; 0 \le x \le \min(\text{targets},\text{capacity}),\; \ell^\top x \le L$$

即国际文献中的非替代/短边均衡（Drèze–Bénassy）。解得的结构性重配置正是需要的：冲击 50% 的电力部门时，电耗强度不同的部门减产幅度不同。

**代价**：每期解一个小 LP。测速后确认在 $n=20$ 时约 1 ms，并加了快速通道——目标可行时直接返回，不解 LP，因此平静期几乎无开销。

**这一节的教训**：教科书的算法在加入产能约束后可能不再收敛，而"它跑不动"往往不是数值问题而是模型问题。

### 优先级阶梯：消费优先为何导致自我强化崩塌

引擎的配给原语只有一个：按优先级层级逐层填充，同层内按比例分配。制度差异通过"申报多少"和"给谁高优先级"来表达。

**第一次运行即崩塌。** 设定"基本消费品最高优先级、生产投入次之"后，一次 40% 的产能冲击让产量在两期内归零。

**机理**：固定数量的最终需求排在中间投入之前，于是短缺时消费先吃掉本已不足的存货，生产部门拿不到投入，产量下降，下一期短缺更大。这是正反馈。存货耗尽后不动点只有零。

**修正**：把默认阶梯改为**生产优先**——中间投入第 0 层，基本消费第 1 层，其他消费第 2 层，政府、投资、储备依次靠后。

这一改动表面上是参数选择，实质上是制度假定。论文因此把阶梯本身设为**实验维度**：`production_first` 与 `consumption_first`。二者的对比不是 bug 与修复，而是结果：**在产能受限经济中，把消费排在生产之前的阶梯会自我强化地崩塌。** 这与 Kornai 关于短缺再生产的论述一致，而它是模型机械地给出的，不是被设定的。

### 存货无界累积与溢损上限

物质平衡机制的分解实验显示，某次运行的**存货达到基年产出 17 倍**。

**诊断**：引擎把每期"生产了但没人用"的商品全部计入期末存货。当计划结构失衡（部分商品过剩、部分短缺）时，过剩的部分被永久堆进仓库，从不出现在成本里。**一个不可售产出免费的经济不是经济。**

**修正**（修订 4）：设定存货上限 `max_stock_ratio = 2.0`（每部门基年产出的倍数），超出部分记为**溢损**（spoilage），进入指标而非静默累积：

$$S_{\text{end}} = \min\bigl(\text{residual},\ \max(\text{cap}-\text{inv},0)\bigr),\qquad S^{\text{spoil}} = \text{residual} - S_{\text{end}}$$

**这不是补丁，而是建模改进**：溢损正是计划驱动经济中"为计划而生产、不为使用者而生产"的产出。实测其规模不小——物质平衡下占供给的 1.4%，试探性定价下 1.8%，四种计划结构自洽的机制恰为 0。

**代价**：恒等式改变，所有结果作废，整个网格重跑。由于单次运行约 45 ms，重跑代价是分钟级，因此判断是"立刻改、立刻重跑"而不是"留作已知问题"。

**治理教训**：这一改动当时**没有**写入冻结的架构文档，被独立验证者在后续检查中发现（F7/P7），最终补为修订 4。项目自己的规则是"允许修订，禁止静默修订"，而我违反了它。

### 指标设计的两个错误

**（a）恢复半衰期恒为 NaN 或 0。** 函数以"燃烧期后窗口内的相对索引"去索引绝对期号，`shortage[start:]` 在 `start = 40`、燃烧期 30 时为空切片。修正为先在窗口内定位峰值，再从峰值之后寻找首次跌破半程阈值的位置——原实现还会在冲击尚未传导时返回 0，因为冲击首期的短缺仍为零。

**（b）放大倍数的分母错误。** 原定义为"峰值短缺率 ÷ (1 − 冲击规模)"，即把一个占产出 2% 的部门被砍 50% 算作**全局** 50% 的冲击，导致放大倍数虚高。修正为按基年产出加权：

$$\text{intensity} = \frac{\sum_j (1-f_j)\,\bar x_j}{\sum_j \bar x_j}$$

同时新增一个同量纲的统计量 `shock_output_amplification`：总产出损失 ÷ 上述加权产能损失。短缺率比的版本保留，但明确标注为"分配比率"而非"网络放大"。

两个错误都指向同一类问题：**分子分母量纲不一致的比率，在小分母处会给出惊人而不实的数字。**

### 机制比较的可识别性：共同参数块

**这是全项目最重要的方法论错误。**

六个机制的代码由不同作者、在不同时间写成，各自带有合理的默认参数。检查发现：

| 参数 | material_balance | 其余四种 |
|---|---|---|
| `backlog_carry` | 0.30 | 0.00 |
| `stock_target_ratio` | 0.10 | 0.15 |

`backlog_carry` 会把上期未满足的需求重新注入本期申报——这是一条**正反馈通道，与协调制度无关**。于是"物资平衡表现最差"这一结论，部分是"物资平衡被额外给了一条别人没有的通道"。

实测（真实 20 部门表、仅噪声、12 个种子）：统一参数下物资平衡产出比 0.9347；把 `revision_gain` 设为 0 后为 **0.9999**。也就是说，**全部劣势来自目标修订增益，而非分配规则本身。**

**修正**：定义唯一的共同参数块，应用于每个机制的每个单元：

```python
MECHANISM_BASE_PARAMS = {"backlog_carry": 0.0, "stock_target_ratio": 0.10,
                         "max_target_ratio": 2.5, "min_target_ratio": 0.25}
```

只有制度旋钮可变（`revision_gain` / `price_gain` / `theta` / `quota_speed`）。实验层在组装每个块时**强制校验**，缺参数即抛出异常——"一个无法识别的排序不能被写进结果目录"。

**代价**：所有已跑完的块重跑。因运行成本低，仍然是分钟级。

**收益**：这条修正把论文的核心比较从"可疑"变成"可识别"，并且顺带产出了更干净的结论：机制之间的差别不在短缺率（五个机制落在 1.56–1.64% 的窄带内），而在产出的浪费（0.97–0.99 对 0.937）。

### 环路增益的估计：回归的偏误

为检验稳定性边界，需要测出 $b$（缺口对工具的反应系数）。初版用**实现路径上的回归**：把短缺率对价格或目标做回归。

**结果符号颠倒。** 对物资平衡估出的 $b$ 为正（看似稳定），而配对增益实验明确显示增益越大短缺越高。

**诊断**：同时性偏误。工具是**对短缺的反应**，所以观测到的是"短缺高时目标也高"，回归捕捉的是反向因果而非政策响应。这条回归的回归元本身就是它要解释的误差的函数。

**修正**：改为**外生位移法**——关闭反馈（增益置 0），把价格外生扰动 ±5%，测量短缺的反应。实验层的 B7 块正是这么做的，得到

$$b_p = 0.125\ /\ 0.197\ /\ 0.342\ /\ 0.616 \quad (\varepsilon = 0.2/0.4/0.8/2.0)$$

近似线性于需求价格弹性，正如机制所要求。这条方法论警示写入论文第 5.5 节。

### 三次错误的机制解释（本报告最重要的一节）

物质平衡在仅噪声条件下损失约 6% 的产出，而同条件下双轨制仅 0.5%。**为什么会这样？** 我给出了三次解释，前两次都是错的。

**第一次：存货估计的不对称（错）**

**假设**：可行性规划对存货估计是不对称的——乐观估计被产能上界吸收（无害），悲观估计砍掉计划（有害）。

**检验**：在基年目标下，把存货从 $0.5r$ 到 $2r$ 变动，规划返回值恒定。原因很干净：$(A-I)x_{\text{base}} = -y_{\text{base}} \le 0$，在任何缩放下都可行——**存货根本不是约束**。

**验证者的判定**：在其机制内部的 86 次平衡规划调用中，$R(0.9r) = R(r) = R(1.1r)$，差值恰为 0。

**第二次：单边过滤 + 投资残余承担（部分对，但不是原因）**

**假设**：平衡步骤是**单边**的（`feasible_output` 返回值必然逐分量不超过目标，因此只能下调不能上调），噪声下跌幅累积；投资位于优先级阶梯底部，承担了缺口，资本存量因此永久下降。

**检验**：两条都成立——计划步骤在 29/80 期下调过目标（增益为 0 时仅 8/80），实际投资从基年比 0.0500 降至 0.0434，资本降至 0.9024。

**但它不是原因**：把存货估计设为无噪声、直接删除、或把初始存货设为 0 与 0.5，损失**逐位不变**。真正的原因是验证者用因果隔离实验找到的。

**第三次：劳动力约束（对）**

**验证者的做法**：逐个关闭通道。

| 干预 | 产出比 |
|---|---|
| 基准 | 0.9087 |
| 产能估计无噪声 | 0.9050 |
| 需求积压估计无噪声 | 0.9072 |
| **删除存货估计** | **0.9083** |
| 初始存货 0 / 0.5 | 0.9061 / 0.9110 |
| **劳动力供给 ×3** | **1.0000** |

只有劳动力一条改变了结论。我自己复现：

| 劳动力供给因子 | 1.05 | 1.15 | 1.40 | 2.00 |
|---|---|---|---|---|
| 产出比（增益 1.0，平衡 3 轮） | 0.8151 | 0.8540 | 0.9964 | 0.9999 |

**完整机制**：测量噪声使家庭在部分季度低估申报 → 计划者观察到短缺 → 增益把目标推高到基年的 1.26–1.40 倍 → 在 1.15 的劳动力供给下该计划需要约 1.22 倍的可用劳动 → 平衡轮次把它投影回劳动可行的前沿，投影是单边的且偏向劳动密集部门（最小填充比 0.23）→ 结构扭曲而非等比缩减 → 投资承担缺口 → 资本存量永久下移。

**这次纠错的方法论价值大于结论本身。** 前两次解释都是"听起来合理且部分可证"的，都通过了各自的部分检验，而都是错的。区分它们的唯一办法是**因果隔离**——逐个关闭通道，看哪一个改变结果。这个逻辑现在写在论文第 6.3 节，也写在验证报告的 F4 中。

**一致性后果**：论文的 Corollary 4（正反馈无安全增益）的**前件是经验性的**，而第三节的分解显示是"劳动前沿投影"把它打开，不是"存货估计"。论文第 4.3 节据此重写了这条推论的定位：它解释为什么耦合环路的代价从第一个增益增量就开始，而分解实验指出是哪个环节触发的。

## 实验设计与预注册修订

### 冻结与修订

预注册在生成任何结果前冻结。之后发生 4 次修订（`docs/AMENDMENTS.md`）与 8 项偏离（`docs/DEVIATIONS.md`）。

**修订 1：环路的符号。** 试点发现目标修订环是**正**的（提高目标反而加剧短缺），因此预注册的边界检验不能跑在计划修订机制上。H1 改在试探性定价的价格环上检验（负反馈经由家庭需求弹性成立），并增设 H1′ 在目标环上同等呈现。

**修订 2：冲击与缓冲的标定。** 试点显示冲击的成本主要由**持续时间相对于存货缓冲**决定，而非深度：35% 冲击持续 12 期造成的峰值短缺是 65% 冲击持续 4 期的三倍。因此标准冲击定为规模 0.50、持续 8 季、初始存货比 0.10。

**修订 3：增益轴。** 检验边界必须变化增益，而预注册设计只变化时滞。B2 因此扩展为"增益 × 时滞 × 机制"三维。

**修订 4：有限仓储（溢损）。** 见 4.4 节。

**偏离记录中最重要的一条**：H1 的判据被重新解释。预注册的判据有两条臂——滞一自相关 > 0.5 且振幅超过无反馈基线三个标准差。第一条臂在本设计中**退化**：受 AR(1) 需求驱动的季度序列，在任何单元（包括完全不设价格的机制）中自相关都在 0.65–0.95。按字面执行会在每个单元宣布不稳定。因此结论改为依托振幅臂，并在论文中明写"判据是在看到其第一条臂无法区分之后重新解释的"。**这是本项目唯一一处看到数据后改变分析规则的偏离**，它被记录而不是被包装成顺利通过。

## 主要结果

**（1）延迟的闭式代价。** $g^\star(m)=2\sin[\pi/(2(2m+1))]$，边界周期 $2(2m+1)$。数学上已验证（四条独立路径，$m$ 至 30，一致性 $2.9\times10^{-11}$；另一路径至 $5.5\times10^{-15}$）。

**（2）信息租金以产出而非短缺支付。** 仅噪声、无冲击时，五个机制的短缺率落在 1.56–1.64% 的窄带内，而产出比为 0.937（物资平衡）到 0.995（双轨制）。**方法学警示**：由于家庭需求对收入有弹性，摧毁产出的机制同时摧毁了本来会记录短缺的需求，短缺率因此近乎不变。只报短缺率的论文会错误地得出"制度无关紧要"。

**（3）紧绷的计划只在劳动力紧张时昂贵。** 增益 1.0 + 3 轮平衡在劳动供给因子 1.05 时损失 18.5%，1.15 时 14.6%，1.40 时 0.4%，2.00 时为零；两个对照（只修订、只平衡）在每个因子下都接近 1.0000。溢损从 0.1% 升至 2.9%。

**（4）下游依赖传播，上游乘数不传播。** 总产出损失随受冲击部门的前向关联（产出中作为中间投入的份额 $(Ax)_i/x_i$）上升：Spearman $\rho=+0.513/+0.567/+0.414$；而用 Leontief 逆的列和（教科书乘数）则完全不相关（$\rho\approx 0$）。**定义敏感性必须披露**：改用教科书的 $A$ 行和定义，相关性降到 $+0.329/+0.313/+0.311$（$p\approx0.16$–$0.18$），不显著。论文两种都报。

### 两个阴性结果

**H1 的边界不可靠地可达。** 实测 $b_p$ 在弹性 0.4/0.8 下为 0.197/0.342，最大环路增益 0.316/0.548，对照 $g^\star(m)$ 只在 $m\ge5$ 或 $m\ge3$ 处接近。预注册判据在 18 个单元中只触发 1 次，且触发点在**边界之下**（实测临界增益为理论值的 57%）。故不宣称跨越。但在增益网格顶端，配对时滞效应确实显著（Wilcoxon 817，$p=4.5\times10^{-12}$）——说明环路的增益提够高时延迟确实起作用。

**H5 形式成立、经济上空洞。** 双轨制份额 θ 的福利曲线在 θ=0.9 处有内部极大，但整个区间（0.122）小于种子标准差（0.067–0.146），且极大点在不同时滞间移动。结论是"检测不到经济意义上的内部最优"，既非证实也非证伪。

## 遗留问题与后续工作

**已知而未解决的：**

1. **表与池化文件的对象不一致。** `paper/tables/lag_grid_reference.csv`（参考增益切片）与 `results/tables/t03_lag_mechanism.csv`（对全部增益池化）是不同对象，物资平衡的短缺率相差最高 67%。论文正文与图注均已披露并指向正确的文件，但**未修复**——实验层已下线。这是提交前应当修的第一项。
2. **§6.3 的因果链略强于证据。** 四个被测量到的通道都按劳动可行性的方向移动，但没有单个单元隔离出这四者中哪一个在做功；只有劳动供给扫描能做到。该节按扫描支持的强度陈述，并明写了这一点。
3. **短边规划的目标函数是总产出最大化**，因此在劳动约束下会把削减集中在劳动密集部门。这是目标函数的性质，不是制度的性质；改用最大最小目标会摊平。未做该对照，已写入局限。
4. **恒定价格价值单位**，非实物量；单一年份 Leontief 技术，无替代；无货币与金融；家庭不跨期优化；企业不博弈计划指标（"按吨位出产"的经典病理留作后续）。

**后续最值得做的三件事**（按我的判断排序）：

1. **把 H1 的检验搬到可稳定运行的价格机制上**：本模型中价格环的增益天然很小，因此边界不可靠地可达。若允许非 Leontief 的边际替代，$b_p$ 可提高一个量级，边界将真正进入可测范围。
2. **指标博弈**：让企业能在"上报需求"上策略性偏离。这会直接激活 Kornai 的软预算约束与信息不对称，且与本文的信息延迟主题同构。
3. **历史校准**：用真实计划经济体的年度物资平衡表回测，检验"紧绷计划 + 劳动紧张 → 产出损失"的条件性预测是否在历史上留下痕迹。

## 结语

这个项目最终交付的东西，比"一个计划经济模拟器"要多，也比"一篇论文"要少。

**多出来的部分**是一套可复用的判断工具：会计恒等式作为硬约束、短边配置作为线性规划、制度与引擎的严格分层、独立验证者的对抗性阅读、以及"改完文件去 PDF 里检索应该消失的字符串"这条朴素实践。

**少掉的部分**是任何一种把结果说得比数据更硬的诱惑。三个假设被证实，两个被证伪或变成空结果，三次机制解释被推翻，一处预注册判据在看到数据后被重新解释并被如实记录。论文里最重要的五个数字旁边都有一句话说明它依赖什么条件。

如果说这个过程有一条贯穿的经验，那是：**在这个项目里，没有一个数字是靠推理得出的。** 定理靠四条独立路径算出来，引擎靠从零重写的一个周期对出来，结果靠两套独立实现交叉校出来，论文里每一句话靠一张 CSV 对出来。我自己的三次机制解释听起来都很合理，两次都通过了部分检验，两次都是错的——最后是因果隔离实验、而不是论证，把它们区分开。

这一点值得写进任何使用本仓库的人的预期里。
